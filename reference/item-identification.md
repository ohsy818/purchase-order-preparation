# 품목 식별

코드로 안 나온다고 바로 신규 등록하면 마스터가 망가진다.
같은 품목이 두 코드로 갈리면 재고가 쪼개지고, 부족 판정도 발주 이력도 어긋난다.

## 탐색 순서

```
1) 코드 완전 일치
2) 코드 부분 일치 (접두어·접미어 차이)
3) 품목명 + 규격 조합
4) 품목명만 (규격 다른 동일 계열 확인용)
5) 공급처 품번 (공급처가 쓰는 코드로 등록돼 있을 수 있다)
```

3번까지 갔는데 후보가 나오면 **자동 확정하지 않는다.** 후보로 제시한다.

## 표기 차이 패턴

같은 품목이 다르게 적히는 흔한 방식이다. 검색어를 변형해 볼 것.

| 패턴 | 예 |
|---|---|
| 어순 | `육각볼트 M5` / `볼트(육각) M5` |
| 구분자 | `M5×20` / `M5*20` / `M5-20` / `M5 20` |
| 한글·영문 | `장갑` / `Glove` / `글러브` |
| 규격 위치 | 품목명에 포함 / 별도 규격 필드 |
| 단위 표기 | `500ml` / `0.5L` / `500cc` |
| 등급·순도 | `99.9%` / `HPLC급` / `특급` |
| 공백·대소문자 | `HexBolt` / `hex bolt` |

## 후보를 제시하는 방법

```markdown
| 검색어 | 후보 코드 | 후보 품목명 | 규격 | 왜 후보인가 |
|---|---|---|---|---|
| 육각볼트 M5×20 | STD-BLT-M520 | 볼트(육각) M5*20 | SUS304 | 규격 동일, 구분자만 다름 |
```

**"왜 후보인가"를 반드시 적는다.** 사람이 1초 안에 판단할 수 있어야 한다.

## 신규로 볼 때

아래를 모두 확인한 뒤에만 신규로 분류한다.

- [ ] 코드 완전·부분 일치 없음
- [ ] 품목명+규격 조합으로 없음
- [ ] 품목명만으로도 유사 계열 없음
- [ ] 공급처 품번으로도 없음

## 같은 계열의 다른 규격

품목명은 같은데 규격이 다르면 **다른 품목이다.** 신규 등록이 맞다.
다만 기존 계열 품목의 카테고리·단위·공급처를 참고해 초안을 채운다.
계열이 있는데 카테고리를 다르게 등록하면 나중에 조회가 어긋난다.

```markdown
| 신규 품목 | 참고한 계열 품목 | 물려받은 속성 |
|---|---|---|
| 육각볼트 M6×20 | STD-BLT-M520 | 카테고리, 단위, 공급처 |
```

## 코드 체계

신규 코드는 **기존 체계를 따른다.** 규칙을 모르면 코드를 비워 두고
「코드 채번 필요」로 표시한다. 임의로 만든 코드가 한 번 들어가면
그 뒤로 계속 예외가 된다.
