# 특수 요건

품목 성격에 따라 주문서에 반드시 남겨야 하는 것들이 있다.
빠뜨리면 물건은 오는데 쓸 수 없거나, 법규 위반이 된다.

## 성격별 요건

| 품목 성격 | 주문서에 남길 것 | 빠뜨리면 |
|---|---|---|
| 위험물·유해물질 | 안전자료 첨부 요구, 보관 조건 | 법규 위반. 입고 거부 사유 |
| 온도 관리 품목 | 운송·보관 온도 조건 | 상온 배송으로 변질 |
| 유효기간 품목 | 잔여 유효기간 최소 요구 (예: 입고 시점 80% 이상) | 곧 폐기할 물건을 받는다 |
| 검교정 대상 | 교정 성적서 동봉 요구 | 사용 전 재교정 비용 발생 |
| 정밀·계측 부품 | 시험성적서, 로트 추적 정보 | 불량 시 원인 추적 불가 |
| 수입 품목 | 통관 서류, 원산지 증명, 인증 | 통관 지연 |
| 규격 인증 필요 | 인증 번호·등급 명시 | 규격 미달품 입고 |
| 세트·조립품 | 구성품 목록 | 부품 누락 |

## 판단 방법

품목 카테고리나 속성으로 자동 판정할 수 있으면 그렇게 한다.
**애매하면 요건을 붙이는 쪽을 택한다.** 불필요한 서류 요구는 번거로울 뿐이지만,
빠진 서류는 입고를 막는다.

```
카테고리 ∈ {시약, 화학품, 용제}     →  안전자료 요구
hazard_class 가 있음                 →  안전자료 + 보관 조건
카테고리 ∈ {시약, 배지, 시약키트}    →  유효기간 요구
카테고리 ∈ {계측기, 센서, 표준물질}  →  성적서 요구
currency ≠ 자국 통화                 →  통관 서류 (수입 추정)
```

## 표기 방법

문서 전체가 아니라 **품목 단위로** 붙인다. 한 문서에 위험물과 일반품이 섞일 수 있다.

```markdown
| 문서번호 | 품목 | 요건 | 근거 |
|---|---|---|---|
| DRAFT-002 | IPA 99.9% 4L | 안전자료 첨부 필요 | 카테고리: 시약·용제 |
| DRAFT-002 | IPA 99.9% 4L | 보관: 인화성, 통풍 | hazard_class 지정 |
```

**근거를 함께 적는다.** 왜 이 요건이 붙었는지 알아야 사람이 판단할 수 있고,
잘못 붙었을 때 고칠 수 있다.

## 승인 규칙과의 관계

특수 요건과 승인 규칙은 **다른 장치다.**

- 특수 요건: 주문서에 **적어야 할 것**. 승인과 무관하게 항상 붙는다
- 승인 규칙: 이 문서가 **결재를 타야 하는지**. `approval_rules`가 정한다

위험물이라서 안전자료를 요구하는 것과, 위험물이라서 부서장 승인을 받는 것은
별개다. 조직에 따라 위험물을 승인 대상으로 두지 않을 수도 있다.
**특수 요건을 승인 판정에 끌어 쓰지 않는다.**
